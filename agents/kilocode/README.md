# kilocode Directory

This directory contains KiloCode-specific configurations.

## Structure

- `workflows/` - Workflow definitions for KiloCode
- `skills/` - (deprecated - now in `agents/skills/`)

**Note**: Skills are now in `agents/skills/` (shared across all agents).

## Global Setup

The global symlink is handled in `agents/README.md`.

KiloCode reads from `~/.kilocode/`.

## Usage

Use workflows by typing `/[workflow-name]` in the KiloCode chat.

## More Info

For more information about KiloCode workflows, visit: https://kilo.ai/docs/customize/workflows
